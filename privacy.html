Privacy policy

Last updated: 22 November 2026

In short: Land and Reason Uploader is a personal script with one user, the owner of the Land and Reason YouTube channel. It uploads that person's own videos to their own channel. It keeps its Google sign-in key only on the owner's computer and shares no data with anyone.

Who this applies to

Land and Reason Uploader ("the script") is run by the owner of the Land and Reason YouTube channel on their own computer. It is not offered to the public and has no other users. If you are not the channel owner, the script never sees, collects or stores anything about you.

What the script accesses

With the owner's consent on Google's sign-in screen, the script uses the YouTube Data API with these permissions, for the owner's own channel only:

  • https://www.googleapis.com/auth/youtube.upload: to upload video files and thumbnails.
  • https://www.googleapis.com/auth/youtube.force-ssl: to set a video's title, description, tags, visibility and publish time, to check its processing status, to read the channel's own video list and counters, and to replace the channel banner when asked.

The script does not read comments, messages, watch history, contacts, email or any other Google data.

What is stored, and where

  • The sign-in key (OAuth refresh token) that Google issues after consent, and the script's own client credentials, are stored in files on the owner's computer.
  • Channel and video information fetched from YouTube is shown on the owner's screen. Lasting copies are not kept beyond a small record for each uploaded video (its YouTube ID, visibility and upload time), saved next to the video file on the same computer.
  • There is no server, database, analytics or advertising component.

Sharing

No data is shared with, transferred to or sold to anyone. The script communicates only with Google's own servers (accounts.google.com, oauth2.googleapis.com and www.googleapis.com), over an encrypted connection.

The script's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

YouTube API Services

The script uses YouTube API Services. Using it means being bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access and deleting data

  • Access can be withdrawn at any time on Google's third-party connections page by removing "Land and Reason Uploader". The stored sign-in key stops working immediately.
  • Deleting the script's key file from the computer removes everything the script has stored about the Google account.

This website

This site is two static pages. It sets no cookies, runs no scripts and has no analytics or forms. The company that hosts the pages may keep standard technical access logs, as any web host does.

Changes and contact

If the script changes in a way that affects this policy, this page will be updated and the date above changed. Questions can be sent through the Land and Reason channel page on YouTube.
